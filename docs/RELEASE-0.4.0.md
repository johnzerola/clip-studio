# Clip Studio 0.4.0

Atualização do painel, revisão e rotina de publicação.

## Destaques

- Tema claro e escuro, aparência do sistema, notas com sinalização por cor e navegação refinada.
- Galeria de clipes com prévia lateral, modo Sala de revisão e player local sob demanda.
- Agenda com status local e confirmação do serviço de publicação apresentados separadamente.
- Verificação diária de novas releases do GitHub. Quando encontrar uma versão mais recente, o painel oferece abrir a página para atualizar.
- Fluxos de lives, VODs, revisão, fila de publicação, CLI e MCP integrados ao pacote.

## Atualizar

Baixe `Clip-Studio-Windows.zip`, extraia para uma pasta nova e execute `Instalar.cmd`. Abra a nova cópia pelo atalho. Para preservar seus dados, mantenha a pasta de resultados, as preferências e os modelos da instalação antiga.

Versões anteriores à 0.4.0 não fazem a verificação automática. Baixe esta primeira atualização pela seção Releases. A partir da 0.4.0, o painel avisa sobre releases futuras.
