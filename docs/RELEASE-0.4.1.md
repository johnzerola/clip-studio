# Clip Studio 0.4.1 — ponte Modelar

- Novo botão Modelar para importar presets aprovados do AI Video Director.
- Verificação de hashes e limites de caminhos, com leitura em fluxo e thread temporária.
- Encaminhamento da edição para a fila compartilhada com acabamento V9, modo Leve e revisão final.
- CLI modelar_bridge.py e ferramenta MCP modelar_reference.
- Nenhuma dependência extra ou serviço residente.

O ritmo importado orienta a revisão. Esta versão não aplica automaticamente a linguagem visual inferida de referências. O novo painel GitHub do usuário ainda será integrado quando seu código estiver disponível.

Validação: compilação e testes sintéticos do importador e composição do pedido. Render e janela gráfica ainda não revalidados nesta máquina, pois a instalação G: está indisponível. Consulte docs/MODELAR.md.

Baixe o ZIP, extraia numa pasta nova e execute Instalar.cmd. Preserve sua pasta de resultados, preferências e modelos.
